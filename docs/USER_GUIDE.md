# 照看使用指南

照看按你设定的条件检查关注公司。条件满足后，提醒保存在网站的“提醒记录”中。当前没有邮件、短信或浏览器后台推送。

## 创建一条提醒

点击右上角“新建提醒”，输入公司和关注条件。例如：

> 未来两周帮我盯住贵州茅台：日内跌幅达到3%，或者发布新的业绩预告，就提醒我。

第一次体验可选择“演示情景（模拟数据）”，不必等待真实市场变化。选择“真实数据”后，系统会向已配置的真实来源取数；来源失败时会显示异常。

点击“查看规则”，核对公司、条件和结束时间。上面的例子会显示“较昨收下跌”“达到”“3%”，以及“发布新的业绩预告”。触发方式选择“满足任意一条”。确认后点击“开始监控”。

“达到3%”包含正好3%；“超过3%”不包含正好3%。下跌幅度填写正数，例如3，系统会转换为正确的比较规则。时间按北京时间处理，结束后自动停止。

公司会从输入中识别。输入未写公司时，可在“公司选择与解析设置”中补充。补充公司与输入冲突时，先纠正冲突再生成规则，不会静默替换。

同一设置中可开关AI解析。开启会把输入发送到已配置的DeepSeek服务；关闭使用本地解析。实际解析路径可在规则页的“技术详情”中查看，模型回退时会有提示。

## 查看和筛选提醒

“我的提醒”显示公司、条件与当前状态。上次检查的结果和时间位于每条提醒下方，行情数值只在取得有效数据时显示。模拟数据始终有单独标识。

顶部可按状态筛选，也可搜索公司、股票代码或提醒条件。“提醒记录”集中显示条件满足、数据异常和恢复通知。

## 修改条件

在任务上点击“修改”，调整条件后点击“保存修改”。可以修改涨跌方向、比较方式和数值，也可以调整公告类别、组合关系与结束时间。检查频率、提醒间隔和交易时段设置放在“更多设置”中。

修改会保留旧规则和历史判断。已有提醒间隔继续生效，保存修改不会清空它。

点击“查看记录”，切到“修改记录”，可查看历史版本。选择“恢复这组条件”会生成一个新版本，历史记录不会被覆盖。已有任务不能改为另一家公司或切换数据模式，这两种情况需要新建提醒。

## 为什么没有提醒

点击任务的“查看记录”，查看实际值、设定条件、来源与检查时间。没有收到提醒，可能因为条件尚未达到、同一事件已经提醒、仍在提醒间隔内，或当前数据无法判断。

提醒间隔内仍继续检查。新发现的公告会先保留，间隔结束后再判断。数据不可用不会被当作条件未满足，也不能据此判断股价平稳。

原始规则和检查记录放在可展开的“本次规则与原始记录”中，需要时可导出。

## 暂停或结束监控

“暂停”停止该任务的检查，已有记录保留。“恢复”让任务重新开始检查。

监控到期会自动结束。点击“归档”也会停止检查并保留历史，确认窗口会说明影响。已归档或到期的任务不能直接恢复，需要重新创建。

## 试一次触发和异常恢复

打开侧栏“演示体验”，点击“创建演示提醒”。核对规则后开始监控，再依次点击“下跌至3.8%”和“继续下跌”，验证同日价格条件不会重复提醒。

点击“新业绩预告”后，公告在提醒间隔内保留。再点击“推进31分钟”，查看间隔结束后的提醒。“行情超时”和“恢复来源”用于检查异常与恢复反馈，更多故障放在“更多测试情景”中。

这些按钮只作用于选中的模拟任务。昨收价为模拟100元，推进的时间属于该任务的演示时钟。真实数据任务不能接受情景注入。

## 手机使用

点击左上角按钮展开导航，选择页面后导航会收起。也可点击导航内的关闭按钮或旁边的遮罩关闭。手机保留创建、修改和检查记录等操作；较长的设置窗口可以上下滚动。

## 页面关闭后会怎样

服务器运行期间，已激活且未暂停的任务会继续检查，提醒保存在站内。重新打开页面后才能查看。

任务保存在服务器，当前浏览器凭访问标识读取。清除Cookie或更换设备后，无法自动找回同一批任务。可以从“查看记录”导出资料；当前不支持跨设备登录或导入恢复。

公开实例依赖本机服务和临时网络通道，电脑、网络或通道停止会影响访问与检查。当前支持选择列表中的12只A股。真实公告检索覆盖有限，可能漏检；量比仅提供演示数据。

仅监控客观事实，不构成投资建议。
